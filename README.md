# 自然考點導航

看懂命題趨勢，找到備考方向。

111–115 學年度學測自然，與分科測驗物理、化學、生物共 20 份試卷、810 題，依物理、化學、生物、地科共 38 個單元歸類，附原題截圖、答案與鷹架式解析。單元依五年配分總和由多到少排列，最常考的放最前面。

**網頁：** https://bgjd315-cloud.github.io/gsat-science-map/

姊妹站：[數學考點導航](https://bgjd315-cloud.github.io/gsat-math-map/)

## 給學生的用法

- 先看題目截圖自己想，再按「開始解題引導」，一步一步點開提問與做法，最後才看答案。
- 物理、化學單元附「本單元公式卡」，生物、地科題目附關鍵觀念框。
- 練習過的題目按「標記已練習」，再用「只看未練習」把它們濾掉。紀錄只存在你自己的瀏覽器。
- 上方可以依考科、科目、年度、難度篩選，或搜尋關鍵字（例如：光電效應、勒沙特列、遺傳）。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網頁本體（題目分類、答案與解析都寫在檔案內） |
| `q/` | 各題原題截圖，檔名為「考科代碼＋年度－題號」：N 學測自然、P 分科物理、C 分科化學、B 分科生物；`-g20` 這類為題組或閱讀文章說明 |
| `art/` | 穿實驗袍的吉祥物「小卡」插圖（以 Canva AI 生成） |
| `tools/` | 產生網頁的程式與逐題資料：`data/` 分類、`detail2/` 解析、`build.py` 建置、`crop.py` 截圖、`check_tex.py` 與 `katex_check.js` 排版檢查 |

## 資料來源與說明

- 試題截圖、參考答案與分科答對率取自[大考中心](https://www.ceec.edu.tw/)公開的歷年試題與統計資料，著作權屬大考中心，本網頁僅供非營利教學使用。
- 解析為教師整理撰寫，非大考中心官方解答；學測未公布逐題答對率，學測題的難度依題目性質判斷。
