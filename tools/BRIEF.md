# 自然科逐題整理說明（分類＋詳解，一次完成）

網站「自然考點導航」把 111–115 學年度學測自然、分科物理、化學、生物逐題依單元分類，附原題截圖與鷹架式詳解，給**中等程度的高中生**練習。你負責指定的試卷，每題產出兩份資料：

1. `tools/data/<代碼><年度>.json`：題目分類資料（格式見下方「一」）。
2. `tools/detail2/<代碼><年度>.json`：詳解（格式見 `tools/DETAIL_BRIEF.md`）。

代碼：N＝學測自然、P＝分科物理、C＝分科化學、B＝分科生物。`exam` 欄寫「學測自然」「分科物理」「分科化學」「分科生物」。

## 你會拿到

- **原題截圖**：`q/`，對照表 `tools/img_manifest.json`（鍵 `"考科|年度|題號"`，例如 `"學測自然|115|13"`；題組或閱讀文章會先列說明圖 `-gNN.png`、`-gNNb.png`）。**每題都要用 Read 打開原圖**，題目、數據、圖表、選項以原圖為準。若截圖缺了題目需要的圖（例如圖在上一題旁邊），打開前後題的截圖找；仍找不到就在回報中列出題號。
- **大考中心檔案**（只讀取，不要在那個資料夾執行任何程式；用 `python -I` 搭配 pymupdf 抽文字，數學式或圖看不清就把該頁轉成圖片再看）：任務說明會給資料夾路徑，檔名 `<代碼><年度>_paper.pdf`（試卷）、`_ans.pdf`（選擇題答案）、`_rubric.pdf`（非選擇題參考答案與評分原則）。**答案一律以大考中心為準。**
- **分科答對率**：任務說明給的 `a<年度>.xls`，用 xlrd、`encoding_override="cp950"` 開；工作表「物理」「化學」「生物」；答對率在 P 欄（百分比，多選題是得分率）。學測沒有答對率。
- **骨架**：`tools/data/<代碼><年度>.json` 目前只有 `exam/year/no`，題數已正確，請整檔覆寫成完整資料（題數、題號不可增減）。

## 一、`tools/data` 每題欄位

```json
{
  "exam": "學測自然", "year": 115, "no": "13",
  "type": "單選",
  "points": 2,
  "unit": "P04",
  "secondary": [],
  "topic": "10 字內的小主題",
  "context": "生活或素養情境簡稱；純學科題填空字串",
  "stem": "60–120 字題意摘要（自己的話，保留關鍵數據；可用 $…$）",
  "answer": "(B)",
  "pitfall": "中等生最容易錯的地方，一句",
  "difficulty": "易",
  "rate": null,
  "verified": true
}
```

- `type`：單選、多選、選填、非選、混合-選擇、混合-非選（題組中的選擇題寫「混合-選擇」，題組中要書寫的寫「混合-非選」；分科的獨立非選擇題寫「非選」）。
- `points`：依試卷說明的配分；非選擇題照題末標示。
- `answer`：單選 `(B)`；多選 `(A)(C)(E)`；非選寫要點（可含 `$…$`）。
- `difficulty`：有答對率時 ≥0.6 易、0.3–0.6 中、<0.3 難；學測依題目性質判斷。
- `rate`：分科填答對率（0 到 1 的小數）；學測與非選擇題填 `null`。
- `verified`：答案與大考中心一致且你自己驗算或推理過填 `true`。

## 二、詳解

依 `tools/DETAIL_BRIEF.md`（自然科版）撰寫，寫到 `tools/detail2/<代碼><年度>.json`。

## 三、完成條件

- 兩個檔都用 Python 產生（`json.dump(..., ensure_ascii=False, indent=1)`，含反斜線的字串一律 raw string），以 `python -I` 執行。
- `python -I tools/check_tex.py tools/detail2/<檔名>.json` 零錯誤。
- 只修改自己負責的這幾個檔，不要動其他檔案。
- 回報 150 字內：題數、與大考中心答案不一致或無法確定的題號、截圖缺圖的題號、遇到的問題。不要把 JSON 內容貼回來。
